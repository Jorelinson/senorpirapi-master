¿Quiénes somos?

Somos tres estudiantes de séptimo semestre de Ingeniería de Sistemas, apasionados por la tecnología y el desarrollo de soluciones innovadoras. Como parte de nuestra formación académica, desarrollamos este proyecto integrador que combina hardware, firmware y software: un sistema de monitoreo de movimiento basado en un sensor PIR conectado a un ESP32, con almacenamiento de datos en una base de datos NoSQL y visualización en tiempo real desde una aplicación web.

Objetivo

Nuestro objetivo es diseñar e implementar un sistema completo de detección y monitoreo de movimiento que permita registrar, almacenar y visualizar eventos en tiempo real. El sistema captura las señales del sensor PIR a través del microcontrolador ESP32, las envía mediante WiFi a un servidor backend desplegado en la nube, y las guarda en una base de datos NoSQL. Desde la interfaz web el usuario puede consultar el historial de movimientos y analizar la actividad del día, el mes o el año mediante gráficas interactivas, facilitando así la toma de decisiones en contextos de seguridad o automatización del hogar.
